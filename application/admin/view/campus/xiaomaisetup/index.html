为何回校后还能开门？

手机上的「开门成功」是小麦自己的页面。

  • 若未走「自行校验」，小麦会先开门，再把记录推给我们
  • 我们拒绝记账（回调里显示「暂无已批准的离校请假」）也关不掉已经打开的门
  • 只有「第三方校验」返回失败时，手机才应无法开门

若回调已拒绝但仍显示「开门成功」：

  1. 联系小麦客服，确认「数据接口 / 自行验证」已绑定且校验失败禁止开门（不要做成仅上报）
  2. 临时拦人：小麦小程序 → 服务 → 黑名单，加入该学生手机号
  3. 或改用「登记/审核」模式，在「用户管理」只放行有请假的手机号
